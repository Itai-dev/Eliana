# Photos

Drop photos here with these exact names. Until a photo exists, the site shows an elegant "ES" monogram instead, so nothing looks broken.

| File | Where it shows | Best shape |
|---|---|---|
| `hero.jpg` | Main portrait at the top (arched frame) | Portrait, 4:5, at least 1200×1500 |
| `story.jpg` | Next to "Her Story" | Portrait, 3:4 |
| `gallery-1.jpg` … `gallery-6.jpg` | "Portfolio" section (appears automatically once any photo exists) | 1 tall portrait, 4 mixed, 6 = wide landscape |

Tips: compress to ~300 KB each (e.g. squoosh.app). Use only photos you have the rights to (her own shoots, or with the photographer's OK).
